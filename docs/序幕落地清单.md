## 1. 系统层新增需求(A 待做,🟡)

### 1.1 岁月洞察技能(§7 PlayerController 侧钩子)

**策划要求**:老年按键 → 场景变暗 + 墙壁显影线索 + 高亮"可爬点"提示。

**接口设计**(建议加到 `PlayerController` 或独立 `InsightMode` 单例):
```csharp
public static class InsightMode {  // 🟡 待实现
    static event System.Action<bool> OnToggled;  // UI/后处理监听:变暗滤镜
    static bool IsActive { get; }
    static void Toggle();          // 老年状态下按 Q 切换(青中年按无效果+提示)
    static void SetActive(bool on);
}
```

**内容层 B 用法**:
- 墙壁幻影 = 一个 SpriteRenderer,默认 alpha=0,监听 `OnToggled` 淡入
- 高亮"可爬点" = 一个粒子/发光对象,同上

**Era 限定**:切换时若 `GameState.CurrentEra != Era.Old`,弹提示"你无法看见过去的幻影",不进入。

### 1.2 Era 切换(§1 GameState 侧扩展)

**当前状态**:`GameState.CurrentEra` 只是 getter,SandboxBootstrap 里通过重建 Player 切换 🟢(调试用)。

**序幕要求**:玩家在剧情节点拾取【遗失物】/【钥匙插入锁孔】/【棺材小游戏】后,以特定动画切换形态,不是按键调试。

**接口设计**:
```csharp
public static class GameState {
    // 新增:
    static event System.Action<Era, Era> OnEraChanged; // (from, to) 🟡
    static void SetEra(Era newEra);                     // 会触发 OnEraChanged + 存档 🟡
    static bool IsEraUnlocked(Era era);                 // 只有解锁过的 Era 才能被玩家主动切 🟡
    static void UnlockEra(Era era);                     // 剧情推进时解锁 🟡
}
```

**画面闪白 + 立绘换装**:监听 `OnEraChanged`,`SandboxBootstrap.BuildPlayer` 抽出成 `PlayerBuilder.Rebuild(Era)`,叠一层全屏白色 UI 淡入 0.3s → 淡出 0.5s。

### 1.3 InteractableBase 加 Era 能力钩子

**当前**:`InteractableBase` 有 `eraRestricted` 字段但没实际 gate 🟢(已埋钩子)。

**序幕要求**:
- 【楼梯攀爬点】= 老年点击 → 弹对白"这腿爬不上去了";青年点击 → 走到爬点 → 播攀爬动画 → 换场景到 UpperHall
- 【铁笼】= 只有青年 + 持有【铁撬棍】才能撬开
- 【齿轮箱】= 只有青年能拽出
- 【组合工作台】= 只有中年能拼接;青年点击弹提示"你毛躁的双手无法完成精密的拼接"

**接口(在 InteractableBase 上补 3 个字段 + 一个 helper)**:
```csharp
public abstract class InteractableBase : MonoBehaviour {
    // ── 已有 ──
    public Era[] allowedEras;                       // 空数组=不限;非空则只有列表内 Era 触发 OnClick 🟡
    public string wrongEraDialogueId;               // Era 不匹配时播的对白(比如"你毛躁的双手…") 🟡
    protected bool RequireEra(Era e);               // helper: return GameState.CurrentEra == e 🟡
}
```

**内部改造**:`RequestInteract` 检查 `allowedEras`,不匹配 → 播 `wrongEraDialogueId`(空则默认"这里我用不了") → 不走 OnClick。

### 1.4 CloseupView 支持"迷你小游戏 prefab"

**当前**:CloseupView 只是 UI 层特写 🟢。

**序幕要求**:三层圆盘旋转小游戏 = 一个 CloseupView 里的 puzzle prefab。已够用 🟢,不用改。

### 1.5 剧情脚本触发器(§New,🟡)

**当前**:DialogueSystem.Show 单条对白 🟢。**没有一个跑"多条对白 + 画面动作 + 等 Flag"的顺序脚本执行器**。

**序幕第 0/4 幕基本是纯脚本**:走到 X → 播对白 A → 播对白 B → 屏幕变暗 → 走到 Y → 剧情杀。

**接口设计**(新加 `Cutscene` 系统):
```csharp
public class Cutscene : MonoBehaviour {  // 🟡 待实现
    // 挂在场景根节点,Inspector 里配一串"步骤":
    //   步骤 = Say(id) / WalkPlayerTo(x) / Wait(seconds) / Fade(color,time) /
    //          Screenshake(intensity,time) / SwitchEra(era) / GoToScene(name) /
    //          SetFlag(k,v) / AwaitClick()
    public void Play();
    public event System.Action OnFinished;
}
```

先做**最小步骤集**:`Say / Wait / Fade / SwitchEra / GoToScene / SetFlag / AwaitClick`。第 0 幕全靠这套。
